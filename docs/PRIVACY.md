# Privacy

Manga/Novel Tracker stores its library, source URLs, reading progress, and refresh metadata in the browser profile only.

It does not use accounts, analytics, advertising, remote code, or a developer-operated server. The extension requests public pages from the five supported sources only to read the latest chapter metadata for series the user has already tracked. Requests omit credentials.

Desktop notifications are optional. Delete a library record or clear extension storage to remove local data.
