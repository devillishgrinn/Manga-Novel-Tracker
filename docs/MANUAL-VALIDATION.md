# Manual validation checklist

Before creating a private release, validate each supported source:

1. Enable tracking from Settings and open a chapter page.
2. Confirm a new dashboard card appears with a non-empty source identity and correct chapter number.
3. Use Resume, edit progress, and refresh the library.
4. Confirm the first refresh creates no notification; simulate or observe a later chapter to confirm one unread count and one optional notification.
5. Export the library, clear extension storage, import the backup, and confirm the source records return.
6. Verify malformed/blocked pages show a source refresh error without affecting other entries.

Run the checklist for Fenrir Realm, HelioScans, Asura, MangaNato/Kakalot, and NovelBin.
